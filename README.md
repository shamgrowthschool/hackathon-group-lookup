# Hackathon Group Lookup

A Next.js app for AI Engineering Accelerator hackathon participants to find their assigned WhatsApp group using their registered email.

## Features

- Case-insensitive email lookup
- Dynamic Google Sheet-backed group lookup
- WhatsApp invite link display
- Hackathon Certificates tab locked for now
- Vercel-ready deployment

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
